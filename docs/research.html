DTI = TP_w / [ TP_w + 0.2 * FP_w + 0.8 * FN_w ]

Because false negatives satisfy the exact identity FN_w = |G| - TP_w, the denominator simplifies to:

Denominator = 0.2 * (TP_w + FP_w) + 0.8 * |G| = 0.2 * N_dots + 0.8 * |G|

Every emitted pixel unconditionally adds 0.2 to the denominator. To increase DTI, the pixel's expected kernel credit k(d) must exceed the marginal credit bar:

Marginal Credit Bar: k(d) > 0.2 * DTI

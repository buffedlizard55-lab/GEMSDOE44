Holdout validation — each stage scored separately

Pre-registered protocol GEMSDOE44-PREREG-1 (fixed before the run, not chosen after seeing results): spatially-blocked 4-quadrant cross-validation, official DTI metric (verified against the published worked example), promotion rules stated up front. Every number on this page is generated by scripts/run_all.py and stored verbatim in data/pipeline_summary.json and the per-step data/*.json receipts — no hand-typed numbers. A submission slot is only spent on an arm that beat the controls on this holdout.

The two questions, two scores, one file. Stage 1 answers “where is geology favourable?” (coarse 2 km zones). Stage 2 answers “where is the fault pixel actually inside those zones?” (single pixels). They are trained on different feature sets, validated on different tasks (zone AUC + concentration vs dot-budget DTI), and reported below as separate tables. The final file can only contain dots inside Stage-1-approved zones, so the file is a product of both — checked in the uniqueness and dominance sections.

Stage 1 — coarse favourability gate (separate validation)

Task: rank 2 km superpixels by the probability that the zone contains any geothermal-relevant fault. Features: strain/kinematics (geod_shearrate, geod_dilaterate, geod_2ndinv), seismicity (deq/ieq), heat-flow well proxies, radiometric TC, depth-to-base, conductivity, gap-link relay endpoints. 30,855 superpixels, 3,490 positive (11.3%). Validated by 4-quadrant block CV (7,626–7,802 blocks per held-out fold) — no leakage from neighbouring blocks.

Stage 2 — fine placement model (separate validation)

Task: inside a Stage-1-approved zone (and outside the 200 m catalogue flank — the winner rule measured in GEMSDOE32), place exactly N 0/1 dots with a 200 m mutual exclusion, maximising the official DTI. 28 fine-scale channels: 19 robust-z physics bands + H1 cross-physics structure-tensor consensus (pair_hi/lo, cmax2_hi/lo) + gap-link relay/endpoints + strike inheritance (H2) + hydrothermal conduit (H4) + seismicity/magnetic edge (H5). A4 = full gradient-boosted model; controls: A0 random, A1 habitat-only (the Stage-1 field itself answering the fine question — the failure mode of prior attempts), A2 single-field ridge, A3 H1-consensus-only.

Each arm emits 10,000 dots per fold in the held-out quadrant; scored with the official DTI against that fold's catalogue pixels.

Why the proxy can mislead (stated before the decision, not after): the Stage-1 gate was trained on the visible catalogue, so the visible-catalogue holdout structurally rewards whatever re-finds the mapped catalogue — exactly what the smooth favourability field does. The hidden test set is faults not in that catalogue, where the gate field has no training signal and the fine structure channels do. The mirror model (off-catalogue, structure-scattered truth) is the less-circular test of which placement generalises; a disclosed dual-arm mirror comparison decides the final placement (see data/mirror_dual_arm.json).

Mirror (live-anchored) truth model — a model, not a score

The hidden test set is faults not in the visible catalogue, so catalogue-based holdout cannot see it directly. Independent re-implementation of the group's own inference (GEMSDOE25 H28): scatter the catalogue with 2-D Gaussian noise (σ swept 1.5/1.85/2.5 px), score candidate files against the scattered copies with the official metric, paired seeds, reported as mean ± SE. Uniqueness + dominance (before calling it “ours”)

Two checks, both mandatory by the brief:

  1. Uniqueness: pixel overlap of the emitted dot set against the four previously-scored incumbent dot sets (GEMSDOE32 h33-2-b2 0.2778, GEMSDOE28 h27-4 0.2708, GEMSDOE25 h19-5 0.2600, GEMSDOE28 topo-gap 0.2449), compared to the random-overlap expectation n₁·n₂/F (F = 5,167,373 footprint cells).
  2. Dominance: the file must not be one stage's footprint wearing the other's name — every dot inside the Stage-1 gate (by construction) and ≥50% of dots sitting on Stage-2-specific structure (H1 consensus at/above footprint p90, or a gap-link relay stamp), so the fine model demonstrably chose the pixels, not just the habitat.

How to read “proxy DTI” honestly

  • Stage-2 holdout DTI = best available pre-submission estimate, but the truth is the visible catalogue inside the held-out quadrants — the live truth is off-catalogue, so expect the live number to sit below the holdout number (the catalogue dots are the easy, well-mapped fraction).
  • Full-catalogue proxy DTI (in pipeline_summary.json) uses the full-data model against the full catalogue — it includes training overlap. It is an optimistic sanity check only, never a score estimate.
  • Mirror model brackets live behaviour assuming the off-catalogue truth is structure-scattered like the catalogue; σ sensitivity is shown explicitly.

The brief's question, answered

Why did GEMSDOE32's h33-2-b2 (0.2778) get the highest in-group score? Because the metric is a budget: each unit of prediction mass that is not the best cover of a truth pixel costs 0.2, and one that is earns at most 1. TPw saturates at 1 per truth pixel (max rule), so the optimal shape is well-separated 0/1 dots placed where a score field is highest — a second dot on the same truth pixel is pure FP cost. h33-2-b2 was the best dot layout the group had, plus a 200 m catalogue-flank removal (mass that can never earn round-1 credit, because the hidden truth is off-catalogue by construction, deleted before emission).

Can we beat the public leader (0.3345 live on 2026-10-06; 0.3195 was the stated target)? Only by raising the credit density of the emitted dots: at the same mass, the metric demands more mean credit per dot. This system attacks that from two directions the group's best file does not combine: (1) a coarse gate that spends mass only where basin-scale favourability is high, and (2) a multi-physics consensus detector — two independent physics fields agreeing on the same lineament — plus catalogue-continuation priors (relay gaps, strike inheritance) that point at unmapped continuations of mapped systems. The holdout numbers are here, per stage; the projected live behaviour is a model, not a score.
